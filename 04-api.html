4. 常用 API 參考

整理本課（講義 03、04 與 Appendix）會用到的函式。每項有：簽名、回傳型別、參數說明、範例、官方文件連結。OpenGL 文件連到 Khronos OpenGL 4 Reference Pages（也可用 docs.gl，可切換版本）。

怎麼讀簽名：GLuint glCreateShader(GLenum shaderType) → 最前面 GLuint 是回傳型別，括號內是參數型別 + 名稱。void = 不回傳。參數型別是 T*（指標）通常代表「你給一塊記憶體，函式把結果寫進去」，例如 glGenBuffers(1, &vbo)。
OpenGL 型別其實就是 C 型別的別名：GLuint=unsigned int、GLint=int、GLsizei=int（數量/大小）、GLfloat=float、GLboolean=unsigned char（GL_TRUE/GL_FALSE）、GLenum=一個常數如 GL_TRIANGLES、GLsizeiptr/GLintptr=byte 數 / byte offset（指標大小的整數）、GLbitfield=可用 | 組合的旗標。
